      What counts as a gesture?

      Cross the activation threshold, then return both axes below the release threshold for the neutral dwell. A pulse must fit the minimum and maximum duration. Long holds and direct reversals are rejected. The stronger axis must satisfy the dominance ratio; pan and tilt are ignored.

      The double window is measured between completed pulses in the same direction. Exclusive mode waits before emitting a single. Immediate mode emits a single first, then an additional double; use it when those actions can coexist. Changing settings cancels pending gestures.

      This lab recognizes cap deflection, not hardware buttons. Defaults are experimental and need physical testing. The adapter supports the existing verified 256f:c63a profile; WebHID availability and permission depend on the browser. Focus loss cancels pending input.
