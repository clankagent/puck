Try manual input & keyboard controls

Hold a direction, then release. Two short pulses make a double. Arrow keys: twist / push / pull. W/S: rx tilt. A/D: ry tilt. I/K/J/L: pan. Hold Shift with a tilt key to push + tilt, or Alt to pull + tilt. Release between actions. Shortcuts are active when no form control is focused.
